## Algunos proyectos

### PlateScan

Aplicación Android para la **detección y reconocimiento de placas vehiculares**, utilizando visión por computadora, YOLOv5, ONNX Runtime y ML Kit.

* [PlateScanApp](https://github.com/JL1704/PlateScanApp)
* [PlateScanBackend](https://github.com/JL1704/PlateScanBackend)

### Max Control

Sistema desarrollado para apoyar la gestión de una empresa de control de plagas, incluyendo una **aplicación Android y un sitio web**.

### SmartLeaf

Proyecto de clasificación de imágenes de plantas utilizando **Machine Learning y Computer Vision**.

### Maze Solver

Proyecto que utiliza **teoría de grafos y algoritmos DFS** para resolver laberintos. El usuario proporciona un laberinto mediante un archivo `.txt` y el programa encuentra una ruta desde el punto de inicio `S` hasta el destino `D`.

* [MazeSolver](https://github.com/JL1704/MazeSolver)
